# 🖥️ Workspace & Window Navigation Guide

## 1. Internal Tabbed Workspace (`panel` Mode)
- Every screen you launch from the sidebar or menu opens as a tab inside your workbench.
- Switching tabs preserves your typed form values as **Drafts**, so you won't lose unsubmitted data when switching back and forth.

---

## 2. Pop-Out Windows (`window` Mode)
- Tellers operating dual monitors can pop out any screen into a separate browser window.
- Click the **Window Pop-out** icon on any screen toolbar.
- Re-launching an open screen will automatically refocus the open popup window instead of opening duplicate windows.
