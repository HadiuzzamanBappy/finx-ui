# 🔍 Customer & Account Inquiries Guide

## 1. Searching Customer Profiles (`INQ`)
1. Open the **Inquiries** menu and select **Customer Search**.
2. Enter the **Customer ID**, **Account Number**, or **National ID**.
3. Click **Search** to view matching results in the data grid.

---

## 2. Viewing Specific Details (`SIR`)
- Click on any row in the inquiry grid to view the complete record details in a single-page view (`SIR`).
- Use the **Print / Export** button to download or print inquiry statements.
