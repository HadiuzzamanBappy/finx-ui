# 🛡️ Maker-Checker Authorizations Guide

## 1. Submitting High-Value Transactions (Maker)
- Transactions exceeding teller limits require supervisor authorization (Maker-Checker 4-Eye Principle).
- When submitting a high-limit transaction, a modal dialog will display: *"Transaction Pending Supervisor Approval"*.

---

## 2. Approving Pending Transactions (Checker)
1. Branch supervisors open the **Authorizations Queue** screen.
2. Review the pending transaction details, teller ID, and amount.
3. Click **Authorize** to complete the transaction or **Reject** with remarks.
