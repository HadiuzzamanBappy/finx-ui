# 📝 Transaction Entry & Draft Auto-Saving Guide

## 1. Entering Financial Transactions
1. Open the target transaction screen (e.g. Deposit, Transfer, Cash Withdrawal).
2. Enter the account details, transaction amount, and narration.
3. Review the summary breakdown.
4. Click **Submit Transaction**.

---

## 2. Automatic Form Draft Preservation
- If you leave a form mid-entry to answer a phone call or switch to an inquiry tab, your entered values are saved as a draft.
- When you return to the tab, your input state is restored automatically.
