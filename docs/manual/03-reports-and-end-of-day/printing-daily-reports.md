# 📊 Printing Daily Reports Guide

## 1. Accessing Report Viewers
1. Open the **Reporting Studio** menu.
2. Select your desired report (e.g., Daily Transaction Journal, Branch Cash Summary, Trial Balance).
3. Select the date range and click **Generate Report**.

---

## 2. Exporting and Printing
- Use the **Export to PDF / Excel** button on the top toolbar to download offline copies.
- Click **Print** to output directly to your branch printer.
