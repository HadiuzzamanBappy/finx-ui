# ❓ Common Error Messages & FAQs

## 1. Frequently Encountered Error Messages

| Error Message | Meaning | Solution |
| :--- | :--- | :--- |
| **"User Session Expired"** | Your login session timed out due to inactivity. | Click **OK** to return to the login screen and re-authenticate. |
| **"Unauthorized Branch Access"** | Your officer account is not assigned to the selected branch. | Select your correct assigned branch code during login. |
| **"Transaction Amount Exceeds Limit"** | The transaction amount exceeds your teller limit. | Submit for manager authorization (Maker-Checker flow). |
| **"Backend System Unavailable"** | The core banking database is currently undergoing maintenance. | Contact system administration if the issue persists. |
